# Aragaw Bayuh Asmamaw — Portfolio Website

A responsive, dark-blue personal portfolio built with plain HTML, CSS and JavaScript for GitHub Pages.

## Files

- `index.html` — page content and sections
- `css/style.css` — responsive styling
- `js/script.js` — mobile navigation, current year and email-form behavior
- `images/profile.jpg` — optional profile photograph location
- `assets/files/Aragaw_Bayuh_CV.pdf` — add your current CV PDF here

## Before publishing

1. Replace the AB initials illustration in the hero with your portrait if you want a photo. The current design intentionally works without a photo.
2. Add your latest CV PDF at `assets/files/Aragaw_Bayuh_CV.pdf`. Until then, the Download CV link will not have a file to download.
3. Review every project description and only keep projects you are comfortable demonstrating to employers.
4. Confirm the email address and certificate links.
5. The contact form uses `mailto:` and opens the visitor's email application. It does not store submissions or send messages through a server.

## Test locally

Open `index.html` in a browser, or use VS Code Live Server.

## Publish to your existing GitHub Pages site

Repository: `aragawbayuh/aragawbayuh.github.io`

1. Back up your current repository before replacing files.
2. Copy `index.html`, `css/`, `js/`, `images/` and `assets/` into the repository root, preserving this folder structure.
3. Commit and push to the `main` branch (or the branch currently configured for Pages).
4. Wait for GitHub Pages to deploy, then refresh https://aragawbayuh.github.io/.

Do not upload the ZIP itself as the website. Extract it first and upload the files and folders inside it.
